Use the same ElevenLabs voice/settings that worked for `error_not_ready_v3_01.mp3`.

Notes:

- Use German text with umlauts. Only use `ue/ae/oe` if ElevenLabs pronounces the umlaut badly.
- I did not find a Tauren male dance voiceover in the WoW sound list, so dance is not part of the replacement set.
- If a file does not exist, `/naxvoice test <key>` will be silent for that key.
